# Progress Report

- Updated **Vanilla Cosmic** to **v3.11.02** for [Mindustry v160.7](https://github.com/Anuken/Mindustry/tree/v160.7).

## October 2026

- Updated **Vanilla Cosmic** to **v3.10.28** for [Mindustry v160.7](https://github.com/Anuken/Mindustry/tree/v160.7).
- Refined block descriptions
- Rebalanced progression, durability, and construction costs.

- Separated the **Vanilla Cosmic** tech tree
- Enabled **Vanilla Cosmic** blocks on Serpulo and Erekir
- Maintained English and Filipino localization.
- Added balance guides
- Added project wiki.

- Released the mod through the Mindustry Mod Browser.
- Established the initial drill, mini-drill, bore, burst-drill, WallCrafter and conveyor lineup.
